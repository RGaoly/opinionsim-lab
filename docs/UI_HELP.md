**云端运行方式**

Streamlit 只负责输入、持久保存配置和查询结果；独立 Python Worker 领取 PostgreSQL 队列并调用 API。关闭浏览器或 Mac 不会停止云端 Worker。数据库应使用付费持久服务，或带持久磁盘并已备份的云服务器。

**操作顺序**

1. 创建项目，导入去标识化数据；真实答案列与画像分开。
2. 保存四套中英文提示语版本。内置内容为流程示例。
3. 建立 2 模型 × 2 语言 × 4 提示 × 6 题配置，生成任务草稿。
4. 检查预算，到运行监控排队；先使用免费模拟模型。
5. 真实 API 必须由部署者设置 ALLOW_PAID_API=true，并在具体实验中输入授权文字。
6. 查看费用、未知请求与无效答案；按段导出或用完整导出工具。

**费用与异常**

费用以配置时填写的每百万 Token 原价计算，所有模型统一币种，不预先减去优惠。每个请求发出前预留最大输出和保守输入预算，多 Worker 共享同一预算锁。模型的特殊计价、缓存和推理 Token 必须与供应商核对；应用预留不是供应商账单的绝对保证。供应商侧也应设置限额。

暂停只影响尚未发出的请求。429 会按退避重试；网络超时、5xx 或 Worker 崩溃后结果未知的请求，保留预留费用为待核对费用，需要核对供应商账单再决定重试。人工重试不会清除历史账单和原始尝试记录。

**方法接口**

analysis.py 提供通用宏平均 F1 和使用 log₂ 的 1−Jensen–Shannon 散度。正式报告前需核对论文中的 MAF1 定义、JS 是否使用距离、加权、分组和缺失处理。当前没有生成论文复现结论。

**维护**

当前为单研究者私有工作台，共享口令不是多人权限系统。完整部署、备份、恢复、导出和学生优惠核查见随包文档。不要向公开 Git 仓库上传 .env、API Key 或调查文件。
